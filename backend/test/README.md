# Test Suite

## Test Files

- `api.test.js` - API endpoint tests
- `admin.test.js` - Admin portal and authentication tests
- `comprehensive.test.js` - End-to-end integration tests
- `unit.test.js` - Unit tests for utility functions
- `bootstrap-wipe.test.js` - Bootstrap token validation and data wipe tests

## Running Tests

Run all tests:
```bash
npm test
```

Run a specific test file:
```bash
npm test -- test/api.test.js
```
